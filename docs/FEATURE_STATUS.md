## 已明确处理的失败边界

- fast 只读文字层；auto 为缺字页 OCR；full 对所有页执行 OCR、画面和物体路径，包括无字页。缺配置返回 `needs_ocr`/`degraded` 等状态；空白 OCR 响应不能冒充已确认无字页。
- 任务原子落盘，含状态、进度、错误、尝试次数与时间；重启把未完成任务标为 `interrupted`，显式重试后才继续，不暗中重放外部调用。
- 未完成配音不能以静音成功代替。只有明确无字页可生成显式静音停留；媒体重生成或重新分析会使旧整片失效。
- 缓存包含图文、模型身份、提示版本与参数；强制重生成会实际调用适配器。完成状态不凭文件名猜测。
- 无相关原文不调用模型编造答案；未配置问答时明确返回原文摘录。缺少页引用、引用检索外页面或未知结构会被拒绝。
- 模型场景描述标为推断；坐标单位和参考尺寸显式声明，不按数值范围猜测归一化。

## 尚不能据此宣称完成的事项

- 真实 OCR、视频、TTS/ASR 与问答供应商调用、额度和响应质量未验收。
- 当前检索基于绘本文字与页/时间定位，不能等同通用视频语义检索；保存图片附件也不表示问答模型已经理解该图片。
- 输出 720p/24fps 不证明原始画质、画风或角色一致性达标；受控配音与静态动画不构成模型演示成绩。
- 整片的音频时间与画面帧边界存在明确量化差异，详见[API/时间轴约定](BOOK_API.md)。
- 持久化任务与会话面向当前单进程本地服务；多进程并发、生产部署及权限体系不在本次验证结论内。

原始样例媒体的历史核查仅证明文件可解析，不能替代当前自动管线验证。[原始导入清单](SOURCE_PROVENANCE.md)保持历史含义，不随本次主线修改重写。
